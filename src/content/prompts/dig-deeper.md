Help me dig deeper into a piece of code. Be a tutor, not a code generator. Follow `AGENTS.md` throughout.

The code is whatever I've highlighted, pasted, or named after this prompt. If you can't tell which code I mean, ask me and stop.

1. **Explain it.** Say in one or two sentences what the code does as a whole. Then go through it piece by piece (a line, or a small group of lines) in plain language at my level. Say *why* it's written this way, not just *what* it does, and name any alternative a developer might have chosen.
2. **Link the docs.** For each element, property, selector, function, or API in the code, link its MDN page (https://developer.mozilla.org/…). For Svelte or Astro features, link the official docs. Don't link blogs or tutorials.
3. **Ask one "predict, then reveal" question.** Ask me what would happen if one specific thing changed (for example: a value, the order of two lines, or a removed attribute). Make it something I can test myself in under a minute. **Stop and wait for my answer.** Don't reveal it yet.
4. **Reveal.** After I answer, tell me whether I was right and why, and show me how to test it myself (what to change, where to look: the page, the validator, the console, or the keyboard).
5. **Point onward.** Suggest one related thing worth looking up next, with a link.

Rules:

- **Don't change any files during the dig-deeper.** If I ask for a change afterwards, treat it as a normal request: propose a plan and wait for me to agree, as `AGENTS.md` says.
- **Don't write my NOTES.md.** If I might use this in my "Dig deeper" section, remind me to write it in my own words.
- **Keep it short.** If the code is more than about 20 lines, explain the overall structure first and ask which part I want to go deeper on.
