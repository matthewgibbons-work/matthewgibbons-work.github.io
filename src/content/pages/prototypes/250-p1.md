# P1 · Color + Typography

Make one Saturday Morning Archive page that spotlights a show you choose, for fans of that show: a color scheme and a type system that feel like the show and stay readable for everyone. It's due Mon Nov 2, with no late penalty. Submit by pasting two links in Learning Suite. Meets means every "done" item; Exceeds adds one extra. Rework until Dec 9.

It puts the Color unit (Mon Oct 26) and the Typography unit (Wed Oct 28) together, and your S03 theme palette is a fine head start for the colors if it suits the page. The content can be short (a heading, a few paragraphs, a list, a link or two); the work is in the look. Check every color pair again on the new page, in WebAIM, not just the ratios the agent states: agents often get them wrong. Then run the W3C validator and zoom to 200% before you call it done. Own-choice option: a page on any topic with a real or realistic audience; say who in your Intent.

## The brief

A fan of the show lands on this page. It should feel like the show at a glance, and stay readable for everyone: people with low vision or color blindness, and anyone reading on a phone in sunlight.

## Spec: the "done" list

<!-- done:start -->

**Color**

- [ ] A palette of 3–5 colors in one format (hex, `rgb()`, or `hsl()`), used consistently.
- [ ] At least one background beyond plain white: a color, a gradient, or an image with a fallback color.
- [ ] Every text/background pair meets WCAG AA contrast (4.5:1 for body text, 3:1 for large text). Check each one with [WebAIM's contrast checker](https://webaim.org/resources/contrastchecker/) and list the results in `NOTES.md`.
- [ ] Color never carries meaning alone: links are distinguishable without color (underline, or similar).

**Typography**

- [ ] One or two web fonts, each with a fallback stack ending in a generic family (`serif`, `sans-serif`).
- [ ] Font sizes in `rem` (or `em` where it's relative to the parent on purpose). No `px` font sizes.
- [ ] Body `line-height` of at least 1.5, and line length kept readable (about 45–75 characters).
- [ ] A heading hierarchy that's clear from the type alone, in a logical order (`h1` → `h2` → `h3`).

**Every Prototype**

- [ ] Landmarks (`header`, `main`, `footer`), and CSS in a separate file.
- [ ] Passes the [W3C validator](https://validator.w3.org/nu/) with no errors.
- [ ] Focus is visible on every link.
- [ ] Readable at 200% zoom (Cmd/Ctrl +): nothing cut off, overlapping, or hidden.
- [ ] Linked from your hub under Prototypes. Live page loads.
- [ ] `NOTES.md` covers every section, in your own words. Meaningful commits.

<!-- done:end -->

**Stretch goal (one way to reach Exceeds):** a dark version using `@media (prefers-color-scheme: dark)` where every pair still meets AA. Show the contrast results for both.

## Working in the loop

1. **Intent:** who is this page for, and what should it feel like? Write it in `NOTES.md` first.
2. **Spec:** start from the list above. Add your palette's mood or the show's era if it helps the agent.
3. **Generate:** ask for a plan first. Have the agent propose the palette *and* the contrast ratios, then check them yourself.
4. **Verify:** check contrast for every pair, run the validator, Tab through the page, and zoom to 200% (Cmd/Ctrl +): is everything still readable with nothing cut off?
5. **Explain:** finish `NOTES.md`, then run [`/check`](/250/skills/check/) `prototypes/p01-color-typography` and paste in the "done" list (the **Copy** button copies it).

**Watch for:** light-gray text on white, links shown only by color, `px` font sizes, `outline: none`, and a font loaded without a fallback.
