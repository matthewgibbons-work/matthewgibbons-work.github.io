# S04 · Fetch one

Fetch one Pokémon from [PokéAPI](https://pokeapi.co/) and show its name, sprite, and types, with a "Loading…" message while it waits and a clear message when the name is wrong or you're offline. Plan on 15–30 minutes. It's due before class on Mon Nov 2 and graded Complete / Not yet straight from your repo, so there's nothing to submit. **Before Monday, install Node.js** (below): Monday's unit needs it.

Keep it to one Pokémon: the form, the whole party, and screen-reader announcements are P1's job. Claude is still on the **Learning** output style, so when it leaves a `TODO(human)` (the error message is a likely one), write that part yourself. The step most people miss is checking `response.ok`: a misspelled name doesn't throw.

## Before Monday

Install **Node.js** (the LTS version from [nodejs.org](https://nodejs.org/en/download)) if you don't have it. Then open Terminal and run `node --version` and `npm --version`: if both print a number, you're ready. Monday's unit sets up npm, Vite, and tests, and needs both.

## 3. Generate

The class worked through these steps together in Try it together; this is your own run, with your intent and the "done" list. Plan mode first: give Claude your intent and the "done" list, and agree on the plan before it writes code. Keep it small: fetch and log first, then render, then the loading and error states.

**Watch for:** no `response.ok` check, errors that only go to `console.error`, `alt="sprite"` or no `alt` at all, and `.then()` chains mixed into an `async` function. If you catch one, it's a good entry for "Accepted / changed / rejected."

## 4. Verify

- Open the live page with the console open. Does the Pokémon appear, with no errors?
- Misspell the name in your code (`pikachuu`) and reload. Is there a clear message on the page?
- In DevTools, open **Network** and set throttling to **Slow 4G**. Reload: can you see "Loading…"? Then set it to **Offline** and reload: is there a message? Set it back to **No throttling** afterwards.
- Check the sprite's `alt` in the Elements panel. Would it make sense read aloud?
